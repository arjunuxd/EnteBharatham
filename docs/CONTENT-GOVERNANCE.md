# Content Governance

## Principles

- Consent and permission to publish are required for public display.
- Withdrawals never delete content; they restrict or archive and revoke publication permission.
- Corrections are community suggestions limited to whitelisted descriptive fields; consent/rights/visibility are never changed by corrections.
- Duplicate detection is advisory only.
- All moderation/governance actions are logged.

## Phase 7 updates

- Media-only withdrawals are validated and actioned (media set to restricted/removed).
- Ownership enforced for contributor withdrawals; moderators can initiate.
- Translations only for publicly eligible records; creation requires owner or moderator.
- Public endpoints never leak private/restricted media or records.
